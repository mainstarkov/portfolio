Dev Port

Проверяет, принимает ли локальное приложение TCP-соединения на заданном порту.

Что умеет проект

  • Проверяет только адрес 127.0.0.1.
  • Принимает номер порта от 1 до 65535.
  • Сообщает об ошибке или тайм-ауте и возвращает код 1.

Требования. Node.js 22+. Устанавливать пакеты не нужно.

macOS

Подготовить Терминал

Установите Node.js для macOS.

Терминал
node --version

Скачать проект

Терминал
git clone https://github.com/mainstarkov/portfolio.git
cd portfolio/projects/nodejs/node-dev-port

Или скачайте ZIP, распакуйте и откройте терминал в папке portfolio-main/projects/nodejs/node-dev-port.

Запустить

Терминал
node main.mjs 3000

Windows

Подготовить PowerShell

PowerShell
node --version

Скачать проект

Или скачайте ZIP, распакуйте и откройте терминал в папке portfolio-main\projects\nodejs\node-dev-port.

Запустить

PowerShell
node main.mjs 3000

Linux

Подготовить Терминал

Установите Node.js через официальный установщик или менеджер пакетов, подходящий вашему дистрибутиву.

Терминал
node --version

Скачать проект

Терминал
git clone https://github.com/mainstarkov/portfolio.git
cd portfolio/projects/nodejs/node-dev-port

Или скачайте ZIP, распакуйте и откройте терминал в папке portfolio-main/projects/nodejs/node-dev-port.

Запустить

Терминал

Как проверить результат

Запустите проект «Кофе по весам» на порту 3000 и повторите команду. Для открытого порта появится is listening.

Адрес и режим работы. Собственный HTTP-сервер отсутствует. Порт передаётся в аргументе.

Исходники. main.mjs проверяет подключение через встроенный модуль Node.js.
