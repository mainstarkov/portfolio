Приём событий

Go Event Inbox принимает события по HTTP, хранит последние 100 записей и распознаёт повторы по ID.

Go 1.22+ · Установить Go ↗ · http://127.0.0.1:8084

macOSWindowsLinux

macOS

Установи Go через пакет .pkg, затем открой «Терминал». Git можно установить командой xcode-select --install, если его ещё нет. Проверь версию командой go version.

Скачать и запустить

Терминал
git clone https://github.com/mainstarkov/portfolio.git
cd portfolio/projects/go/go-event-inbox
go run .

Без Git: скачай ZIP и распакуй. В распакованной папке открой portfolio-main/projects/go/go-event-inbox и выполни go run ..

Проверить API

Оставь сервер запущенным. Эти команды введи во втором окне.

Терминал
curl -sS http://127.0.0.1:8084/healthz
curl -i http://127.0.0.1:8084/events \
  -H 'Content-Type: application/json' \
  -d '{"id":"demo-1","type":"order.created"}'
curl -sS http://127.0.0.1:8084/events

Windows

Установи Go через .msi и открой новое окно PowerShell. Для клонирования понадобится Git для Windows. Проверь версию командой go version.

Скачать и запустить

PowerShell
git clone https://github.com/mainstarkov/portfolio.git
Set-Location .\portfolio\projects\go\go-event-inbox
go run .

Без Git: скачай ZIP и распакуй. В распакованной папке открой portfolio-main\projects\go\go-event-inbox, открой там PowerShell и выполни go run ..

Проверить API

Оставь сервер запущенным. Эти команды введи во втором окне.

PowerShell
$base = 'http://127.0.0.1:8084'
Invoke-RestMethod "$base/healthz"
$event = @{ id = 'demo-1'; type = 'order.created' } | ConvertTo-Json -Compress
(Invoke-WebRequest -UseBasicParsing -Method Post -Uri "$base/events" -ContentType 'application/json' -Body $event).StatusCode
(Invoke-WebRequest -UseBasicParsing -Uri "$base/events").Content

Linux

Установи Go по официальной инструкции для Linux. Если Go уже установлен, но терминал его не видит, проверь, что /usr/local/go/bin добавлен в PATH. Для клонирования понадобится Git. Проверь версию командой go version.

Скачать и запустить

Терминал
git clone https://github.com/mainstarkov/portfolio.git
cd portfolio/projects/go/go-event-inbox
go run .

Без Git: скачай ZIP и распакуй. В распакованной папке открой portfolio-main/projects/go/go-event-inbox и выполни go run ..

Проверить API

Оставь сервер запущенным. Эти команды введи во втором окне.

Терминал
curl -sS http://127.0.0.1:8084/healthz
curl -i http://127.0.0.1:8084/events \
  -H 'Content-Type: application/json' \
  -d '{"id":"demo-1","type":"order.created"}'
curl -sS http://127.0.0.1:8084/events

Что должно получиться

  • GET /healthz возвращает ok.
  • Первый POST /events с ID demo-1 возвращает 201 Created. Повтор той же команды возвращает 200 OK.
  • Повтор с тем же ID и другим типом возвращает 409 Conflict.
  • GET /events возвращает список событий в JSON.

Сервис запускается на http://127.0.0.1:8084 на твоём компьютере. Чтобы остановить его, нажми Ctrl + C в первом терминале. При остановке записи очищаются.
