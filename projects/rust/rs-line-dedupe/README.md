# rs-line-dedupe

Удаляет повторяющиеся строки UTF-8, сохраняя порядок первых вхождений.

## Запуск

```sh
cargo run -- example.txt
```

## Как проверить

Результат содержит две строки: `pear` и `apple`.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/rs-line-dedupe/).

Терминальная утилита, HTTP-порт не требуется.
