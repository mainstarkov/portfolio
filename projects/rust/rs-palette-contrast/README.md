# rs-palette-contrast

Считает коэффициент контраста двух цветов sRGB по формуле относительной яркости.

## Запуск

```sh
cargo run -- '#202020' '#ffffff'
```

## Как проверить

Для чёрного и белого результат будет `21.00:1`.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/rs-palette-contrast/).

Терминальная утилита, HTTP-порт не требуется.
