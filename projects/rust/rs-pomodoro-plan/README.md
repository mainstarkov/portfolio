# rs-pomodoro-plan

Рассчитывает расписание фокус-сессий и перерывов по минутам от начала.

## Запуск

```sh
cargo run -- 3 25 5
```

## Как проверить

Последняя сессия заканчивается на 85-й минуте.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/rs-pomodoro-plan/).

Терминальная утилита, HTTP-порт не требуется.
