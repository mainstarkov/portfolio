# rs-week-grid

Генерирует Markdown-таблицу на семь дней для списка привычек.

## Запуск

```sh
cargo run -- Walk Read
```

## Как проверить

Таблица содержит две строки привычек и семь колонок для отметок.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio-projects/rs-week-grid/).

Терминальная утилита, HTTP-порт не требуется.
