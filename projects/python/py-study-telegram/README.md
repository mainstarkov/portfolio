# py-study-telegram

Telegram-бот для повторения карточек. Команда /card выдаёт вопрос, /answer показывает ответ последней карточки в чате.

## Запуск

```sh
python3 main.py --demo
```

## Как проверить

Демо показывает карточку про столицу Японии. Для реального запуска задайте `TELEGRAM_BOT_TOKEN` и запустите `python3 main.py`. Карточки меняются в `cards.json`. Позиция сбрасывается при перезапуске.
