# py-subscription-ledger

Сводит месячные и годовые подписки к годовому бюджету. Суммы считаются через Decimal.

## Запуск

```sh
python3 main.py example.csv
```

## Как проверить

Пример должен показать годовой итог 180.00. Используйте одну валюту на файл.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/py-subscription-ledger/).

Терминальная утилита, HTTP-порт не требуется.
