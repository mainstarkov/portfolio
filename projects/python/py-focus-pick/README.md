# py-focus-pick

Выбирает, за какую задачу взяться, с учётом важности и оценки времени.

## Запуск

```sh
python3 main.py example.csv
```

## Как проверить

При бюджете 30 минут будет предложено `Reply to feedback`.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/py-focus-pick/).

Терминальная утилита, HTTP-порт не требуется.
