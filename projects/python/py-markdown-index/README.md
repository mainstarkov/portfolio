# py-markdown-index

Строит Markdown-каталог заметок из заголовков и относительных ссылок.

## Запуск

```sh
python3 main.py notes
```

## Как проверить

В каталоге появится ссылка на «Первую заметку». Сохраняйте вывод рядом с папкой заметок.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio-projects/py-markdown-index/).

Терминальная утилита, HTTP-порт не требуется.
