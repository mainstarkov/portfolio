# RepoMap

Локальная утилита на Go, которая строит интерактивную карту папки Git. Она показывает связи стрелками и указывает файл и строку для каждой записи.

- **Сайт** — переходы по локальным ссылкам и отправка HTML-форм. Во вкладке «Сайт» можно пройти цепочку по найденным переходам.
- **HTTP API** — статические маршруты `Handle` и `HandleFunc` в Go.
- **Telegram-бот** — найденные в коде команды, подписи кнопок и литералы callback, если они объявлены рядом.

[Открыть пример карты на GitHub Pages](https://mainstarkov.github.io/portfolio/repomap/)

## Установка и запуск

Нужны Go 1.22+ и Git. В корне клона портфолио выполните:

```sh
cd projects/go/repomap
go build -o ./repomap .
```

Перейдите в каталог своего проекта и запустите собранный файл:

```sh
cd /путь/к/моему/проекту
/путь/к/portfolio/projects/go/repomap/repomap -out mapa.html .
```

Откройте `mapa.html` в браузере. Сервер, порт и интернет для готового отчёта не нужны. Чтобы сохранить следующую версию, укажите новое имя файла. На Windows используйте `go build -o repomap.exe .`.

## Что читает анализатор

RepoMap берёт список файлов через Git. Учитываются отслеживаемые файлы и новые файлы, которые Git показывает с учётом правил игнорирования. Символьные ссылки и исходники больше 2 МиБ пропускаются. Код проекта не запускается и никуда не загружается.

HTML-переходы и формы ищутся в исходниках, маршруты Go разбираются из синтаксического дерева, а команды и кнопки извлекаются по шаблонам. Генерируемые маршруты SPA, подставляемые из переменных callback и фактические сценарии пользователей могут отсутствовать. Совпадения для Telegram стоит проверить по указанным файлу и строке.

## Повторить опубликованный пример

Папка `example/` содержит синтетические исходники для карты: три страницы, два маршрута API и фрагмент Telegram-бота. Чтобы повторить демонстрацию в отдельной папке:

```sh
demo_dir="$(mktemp -d)"
cp -R example/. "$demo_dir"/
git -C "$demo_dir" init
./repomap -out example-map.html "$demo_dir"
```
