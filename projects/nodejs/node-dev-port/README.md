# node-dev-port

Проверяет, доступна ли локальная TCP-связь с приложением на указанном порту.

## Запуск

```sh
node main.mjs 3000
```

## Как проверить

Запустите один из лендингов, например node-coffee-ratio на порту 3000 и выполните команду повторно. При открытом порте появится `is listening`.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio-projects/node-dev-port/).

Проверяет локальный TCP-порт, собственный сервер не запускает.
