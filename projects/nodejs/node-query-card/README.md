# node-query-card

Преобразует параметры строки запроса в JSON. Повторяющиеся ключи сохраняются как массивы.

## Запуск

```sh
node main.mjs 'tag=go&tag=rust&q=hello+world'
```

## Как проверить

Поле `tag` содержит два значения, поле `q` — строку с пробелом.

## Демо и адрес запуска

[Открыть пример в браузере](https://mainstarkov.github.io/portfolio/node-query-card/).

Терминальная утилита, HTTP-порт не требуется.
